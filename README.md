# AI-Travel-Planner-Recommendation-System
A Python-based AI Travel Planner Recommendation System using Content-Based Filtering and Cosine Similarity to recommend travel destinations based on user preferences.
AI Travel Planner Recommendation System
Overview
The AI Travel Planner Recommendation System is a Python-based academic project that recommends travel destinations based on user preferences. It uses Content-Based Filtering and Cosine Similarity to compare destination features and identify suitable travel options.
Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Visual Studio Code
Key Features
- Personalized travel destination recommendations
- Content-Based Filtering algorithm
- Cosine Similarity calculations
- Data cleaning and preprocessing
- One-Hot Encoding for categorical variables
- StandardScaler for recommended stay duration
- Model testing and evaluation
Dataset
The project uses the Travel Planner Dataset on Kaggle.
Features used in the recommendation model:
- Destination_Type
- Travel_Mode
- Best_Season
- Recommended_Stay_Days
How It Works
1. Load the travel dataset using Pandas.
2. Clean and preprocess the dataset.
3. Encode categorical features using One-Hot Encoding.
4. Standardize recommended stay duration using StandardScaler.
5. Apply Content-Based Filtering and Cosine Similarity.
6. Generate destination recommendations based on user preferences.
7. Test and evaluate the recommendation results.
Project Files
- model_training.py — Model implementation
- model_testing.py — Test cases
- model_evaluation.py — Model evaluation
